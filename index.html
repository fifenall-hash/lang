💡 내장 TTS 추가 설치 및 고품질 음성 설정 안내 보기

• Android (갤럭시/태블릿): [설정] → [일반] → [글자 읽어주기(TTS)] → [선호하는 엔진(삼성 TTS 또는 Google 음성 서비스)] 옆 톱니바퀴 → [음성 데이터 설치]에서 해당 언어를 다운로드하세요.

• iOS / iPadOS (아이폰/아이패드): [설정] → [손쉬운 사용] → [콘텐츠 말하기] → [음성]에서 학습할 언어(영어/일본어/중국어/베트남어/아랍어)를 선택 후 고품질 음성을 다운로드하세요.

• Windows PC/태블릿: [설정] → [시간 및 언어] → [음성] → [음성 추가]에서 원하는 언어 팩을 설치한 뒤 브라우저를 재시작하세요.
