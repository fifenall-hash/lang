• Android (갤럭시/태블릿): 안드로이드 크롬은 기기에서 선택된 대표 성우 1명만 전달합니다. [설정] → [일반] → [글자 읽어주기(TTS)] → [Google 음성 서비스 ⚙️] → [음성 데이터 설치] → [영어(미국)]에서 남성 목소리(음성 II / IV 등)로 바꾸고 앱을 재실행하면 en-US가 실제 미국 남성 성우로 작동합니다.

• iOS / iPadOS: [설정] → [손쉬운 사용] → [콘텐츠 말하기] → [음성] → [영어]에서 Aaron / Nicky / Alex 등 미국 남성 음성을 다운로드하세요.
